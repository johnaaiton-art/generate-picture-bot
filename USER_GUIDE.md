# Bot Usage Guide

## Three Modes of Operation

### Mode 1: Chinese → Chengdu Scene Image
**Input:** Any Chinese text (without "col" or "collocation")

**Example:**
```
User: 美好生活
Bot: 🧠 正在理解"美好生活"...
Bot: 🎨 正在生成图像，请稍候...
Bot: [Sends image of Chengdu scene]
```

**What happens:**
1. Bot detects Chinese characters
2. Uses Qwen to rewrite as vivid Chengdu scene description
3. Sends to Yandex Art API
4. Returns generated image

---

### Mode 2: English → Literal Image
**Input:** Any English text

**Example:**
```
User: A cat playing piano in a jazz club
Bot: 🎨 Generating: "A cat playing piano in a jazz club"...
Bot: [Sends image exactly as described]
```

**What happens:**
1. Bot detects no Chinese characters
2. Uses your exact text as the image prompt
3. Sends to Yandex Art API
4. Returns generated image

---

### Mode 3: Chinese Word → Collocations
**Input:** Chinese word + space + "col" (or "collocation")

**Example:**
```
User: 途径 col

Bot: 📚 正在查找 "途径" 的常用搭配...
Bot: ✅ 找到 5 个常用搭配：
     点击按钮保存到表格
     
     [Button: 有效途径 effective means]
     [Button: 法律途径 legal channel]
     [Button: 外交途径 diplomatic channels]
     [Button: 和平途径 peaceful means]
     [Button: 通过正式途径 through official channels]
```

**Then when you click a button:**
```
Bot: ✅ 已保存:
     中文: 有效途径
     英文: effective means
     
     已添加到表格！
```

**What happens:**
1. Bot detects pattern: `[Chinese] col` or `[Chinese] collocation`
2. Uses Qwen to generate 5 common collocations
3. Displays as clickable Telegram buttons
4. When clicked, saves both Chinese + English to your Google Sheet

## Important Notes

1. **"col" must be separated by a space**: 
   - ✅ `途径 col`
   - ❌ `途径col` (won't trigger collocation mode)

2. **Case doesn't matter**:
   - `途径 col` = `途径 COL` = `途径 Collocation`

3. **Image generation is slow**:
   - Takes 1-3 minutes typically
   - Bot will notify if taking >30 seconds

4. **Collocations are generated by AI**:
   - Should be accurate for common words
   - May need manual verification for specialized terms

5. **Google Sheet format**:
   - Column A: Chinese collocation
   - Column B: English translation
   - New entries append to bottom
